# Changelog

Summary of development milestones recorded in the project. Version names are taken from the earlier development notes; no release dates have been assigned.

## Recent development

- Added Firebase accounts, usernames, cloud saves and leaderboards, with an API for ranked runs.
- Added daily challenges, progress tracking and claimable XP rewards.
- Introduced shared difficulty profiles and more varied evidence across Arcade modes.
- Continued improvements to scenario variety and repetition prevention.

## v13 — Code organization and replayability

- Organized Dart source into models, views, controllers and services.
- Improved scenario selection and reduced predictable answer patterns.
- Kept menu music consistent when switching tabs.

## v12 — Navigation and progression

- Added bottom navigation, mascot customization and investigator level rewards.
- Updated profile and Arcade progression screens.

## v11 — Audio and interactions

- Added bundled background music and sound effects with volume controls.
- Improved Inbox Sprint card flipping, swiping and mobile layout.

## Earlier development

- Established Career Shifts and the Arcade mini-games.
- Improved mobile layouts, tutorials and feedback.

See [Testing](docs/TESTING.md) for checks to run before a release.
